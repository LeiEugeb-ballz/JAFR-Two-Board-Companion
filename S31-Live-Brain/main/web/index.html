Gateway routing

Automatic mode discovers the PC gateway at boot and follows its current address. Manual mode pins the route for controlled networks. Changes are stored on the board and take effect after restart.

Voice pipeline

Direct mode streams 16 kHz microphone audio to Mistral, streams reply text into realtime PCM speech, and plays it through the selected speaker. The key is never shown by this page. PC mode preserves the proven UDP gateway fallback.

Response speaker

S31 always plays the boot sound. Auto prefers DualEye while BLE is ready and falls back to S31. Manual selection is retained; change it while idle.
